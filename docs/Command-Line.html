Command line

OSCAT has two commands. Both are installed by every installer (on Windows they are added to the PATH). --help after any command lists all its options.

oscat: the scanner

Works on its own, without the web server, from YAML profiles and inventories.

Command Does
oscat validate PROFILE checks a profile for mistakes
oscat scan -p PROFILE -i INVENTORY [-g GROUP] [-H HOST] [-c CONTROL] [-o results.json] [--csv FILE] scans hosts; -g, -H, -c repeat; --parallel-hosts (50) and --parallel-checks (4 per host)
oscat evaluate RESULTS -p PROFILE -o OUT re-judges saved evidence with a changed profile, without touching the hosts
oscat report RESULTS [--failures] [--csv F] [--xlsx F] [--pdf F] [--title T] [--host H] [-p PROFILE] prints a summary and writes reports; --host makes a one-host report
oscat collector -p PROFILE [-o PATH] [--label L] [--days 90] writes an offline collector and its .collector.json record
oscat import-collected FILES... -p PROFILE -k RECORD [-g GROUP] [-o results.json] [--force] evaluates collector results files
oscat import-pdf PDF -o FOLDER [--llm ollama --model M] [--pages A-B] [-c CONTROL] drafts a profile from a CIS PDF
oscat import-legacy --scripts DIR --id ID --title T -o FOLDER [--excel F] converts OSCAT v1 scripts to a profile

Secrets in an inventory are references, never plain text: {env: VAR}, {prompt: label} or {file: path}. See Credentials and targets.

Example:

export OSCAT_SSH_PASSWORD=...
oscat validate profiles/cis-ubuntu-22.04/profile.yaml
oscat scan -p profiles/cis-ubuntu-22.04/profile.yaml -i inventory.yaml -g web -o results.json
oscat report results.json --failures
oscat report results.json --xlsx audit.xlsx --pdf audit.pdf -p profiles/cis-ubuntu-22.04/profile.yaml

oscat-server: administering the web app

Run as root (Linux) or in an administrator prompt (Windows) so it can read the settings file and the master key.

Command Does
oscat-server create-user NAME [--role admin\|auditor\|viewer] adds a user; prompts for the password
oscat-server import-profile PATH adds a profile folder, YAML or zip
oscat-server gen-cert [--name N]... [--force] creates a self-signed certificate

For a Docker install, run them inside the container: cd /opt/oscat-docker && docker compose exec api oscat-server create-user alice --role auditor.
