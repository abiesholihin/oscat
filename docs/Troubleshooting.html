Troubleshooting

The web page does not open

  • Check the service: systemctl status oscat and journalctl -u oscat -n 50 (Windows: Get-Service OSCAT and C:\ProgramData\OSCAT\logs; Docker: cd /opt/oscat-docker && docker compose ps and docker compose logs api).
  • Use https, not http, and port 8443 (or the OSCAT_PORT you set).
  • From another machine, open port 8443 in the jumphost's firewall (see Installation).
  • The browser's certificate warning is expected with the self-signed certificate; install your own certificate to remove it (settings).

I lost the setup code

It is in /var/lib/oscat/setup-code (Windows: C:\ProgramData\OSCAT\setup-code; Docker: docker compose exec api cat /var/lib/oscat/setup-code). It disappears once the first administrator exists; after that, add administrators with sudo oscat-server create-user <name> --role admin.

A host shows a connection error

The host table shows the reason. Common ones:

Message mentions Check
timeout, connection refused network path and firewall from the jumphost to port 22 / 5986 / 5985 / 443
authentication failed the credential's user name and password or key; for WinRM, the authentication type
host key changed / unknown the host was rebuilt (click forget pinned key on the Targets page), or Strict is set and the key is not known yet
WinRM certificate has changed the certificate was renewed: click forget pinned key on the Targets page, or check why it changed
certificate verify failed OSCAT_CA_BUNDLE, or the scan's certificate check setting
not attempted 3 hosts in a row refused the login, so the scan stopped logging in; fix the credential and run it again

Many controls are "Error"

Open one in the host's evidence; the check shows the reason.

  • Privilege escalation failed (wrong sudo password, user not in sudoers, su needs a different password): fix the scan's become settings or credential. Only checks marked privilege: root are affected.
  • Command not found: the host lacks a tool the check uses; the profile may need a different command for this OS.
  • Permission denied without escalation: the target has no become method, but the check needs root.

After fixing the profile, re-judge saved results with oscat evaluate instead of rescanning (Running scans).

An uploaded collector file is refused

Reason What to do
collected on another OS the wrong collector was run; issue one for that OS, or tick Accept files collected on another OS if you are sure
files come from different collectors upload each collector's files separately
collected after this collector stopped working the host's clock was past the end date; extend the collector, download the script again and collect again
revoked OSCAT no longer accepts its results; issue a new collector and collect again
signature does not match the file was edited or truncated; collect again
written by a collector this OSCAT did not issue the collector came from another OSCAT server, or its record was deleted

PDF import finds few controls or drafts poorly

  • Use the original CIS PDF, not a scanned or printed copy.
  • Every control starts as review: needed; low confidence is normal for controls whose audit depends on site policy.
  • A local model improves drafts (setup). If it is set but unused, check that Ollama is running and OSCAT_OLLAMA_URL reaches it.

Stored credentials cannot be decrypted

The master key does not match the data, for example after restoring the data without its key. Restore the matching master.key; without it, re-enter the credentials.
