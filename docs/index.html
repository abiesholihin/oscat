Releases

OSCAT v2

OSCAT (One Stop CIS benchmark Auditing Tool) audits the configuration of servers and appliances against CIS benchmarks. It runs on one machine, usually an isolated jumphost, logs in to the hosts it audits, and produces Excel and PDF audit reports. Nothing is installed on the audited hosts.

What it does

  • Controls with several checks and logic. A control can run many commands and combine their results with and, or, not, at_least and if/then.
  • Control dependencies. A control can run only when another control passed, and otherwise be reported as not applicable or skipped.
  • CIS PDF import, offline. Upload a CIS benchmark PDF; OSCAT drafts a profile from it without internet access (optionally helped by a local AI model) and you review each control.
  • More ways in. SSH with password or key, through a jump host; WinRM for Windows; the REST API for Cisco APIC; privilege escalation with sudo, sudo -i, sudo su -, su, dzdo, doas, pbrun or pmrun.
  • Windows settings and web-managed appliances. Registry, security policy, user rights, audit policy and services on Windows; the APIC management model for Cisco ACI.
  • Grouped scans. Scan tens to hundreds of hosts at once, by group or one by one.
  • Offline collector. For hosts the jumphost cannot reach, hand out a script whose signed results file OSCAT evaluates like a normal scan.
  • Reports. Excel (cover, dashboard, details) and PDF reports per scan or per host, plus CSV.

Result states

Every control on every host ends in one of these states:

State Meaning
Pass The host meets the control.
Fail The host does not meet the control.
Error OSCAT could not collect or judge the evidence (connection lost, command missing, permission denied).
N/A The control does not apply to this host (applicable_if, or a dependency that says so).
Skipped A control it depends on did not reach the required result. The Observation names that control and its result.
Manual The benchmark asks for a human judgement; evidence is gathered for the reviewer.
